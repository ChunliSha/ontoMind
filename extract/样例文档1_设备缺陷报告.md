# 变电站设备缺陷报告

**报告编号：** QX-2026-0731

| 字段 | 内容 |
|---|---|
| 所属变电站 | 龙泉220kV变电站 |
| 设备名称 | 1号主变压器 |
| 设备编号 | BY-2018-001 |
| 设备类型 | 油浸式电力变压器 |
| 额定电压 | 220kV |
| 额定容量 | 180MVA |
| 生产厂商 | 华光电气制造有限公司 |
| 投运日期 | 2018-06-15 |

## 缺陷描述

2026年7月31日夜间巡检时，运维人员发现1号主变压器本体油枕油位异常偏低，且在储油柜下方发现明显油渍渗漏痕迹，伴有轻微异响。经初步判断，渗漏点位于油枕与本体连接法兰处密封垫老化失效，若不及时处理可能导致绝缘油持续流失，威胁设备安全运行。

- **缺陷等级：** 严重缺陷
- **发现日期：** 2026-07-31
- **发现人：** 王建国（巡检员，工号 XJ-1024）
- **当前状态：** 待安排检修

## 后续处理

该缺陷已录入缺陷跟踪台账，已同步生成检修工单 JX-2026-0812，安排专业检修班组尽快处理，处理前已加强巡视频次并做好油位监测记录。
